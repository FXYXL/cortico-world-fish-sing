# 大肥鱼唱歌 · 训练教程

> 面向第一次用训练面板的人。跟着做，从一堆歌到一个能唱的模型，大约需要**半天**（其中 2~3 小时是训练本身，不用盯着）。
> 界面分三步折叠：**① 素材 → 数据集**、**② 训练**、**③ 高级：低音增强 / 音域加权**。平时只需要动 ① 和 ②。

---

## 0. 开始之前：素材怎么选

| 要求 | 说明 |
|---|---|
| 干声最好，带伴奏也行 | 带伴奏的会自动用 demucs 分离出人声，但分离总会有点残留，**能找到干声就用干声** |
| 音质 > 数量 | 30~60 分钟清晰人声就够训出一个能用的模型；素材糊、混响重，训出来也糊 |
| 同一个人 | 全部素材必须是同一个音色（想换音色就另开一个实验） |
| 格式 | mp3 / wav / aac / flv 都行，面板自动转 |

---

## 1. ① 素材 → 数据集

1. **粘贴路径**：把放歌的文件夹（或单个文件）路径粘进输入框，多个用 `;` 分隔，点「扫描」。
   - 直接读本机磁盘，不复制文件。
2. **看扫描结果**：文件表会列出每个文件的时长、响度，以及自动判断「已是干声」还是「含伴奏」。
3. **切片**：
   - 「切片方式」保持默认（按乐句自适应）就好；
   - 「切片时长」默认 2–4.5 秒，不用改；
   - 点「开始切片」。**别勾「追加到当前数据集」**——那是想把新素材并进旧数据集时才用的。
4. **看音域分布**：切完会出现统计和音域分布图。`低` 档太少（比如 <1 分钟）说明素材里低音少——模型就学不会低音，这是数据问题，不是训练问题。
5. **选数据集**：在「数据集」下拉里选中刚切好的那个。信息栏会显示已训出的模型。

> ⚠️ 切片完成后**伴奏就被删了**（只留人声，一首省 40 MB），想留伴奏自己先备份。

## 2. ② 训练

| 参数 | 怎么填 | 说明 |
|---|---|---|
| 实验名 | 随便，已预填 `fishMMDD` | 同名会复用目录；产物在 `logs/<实验名>/` |
| 轮次 | **40~70**（推荐） | 越多越久；数据量 30 分钟左右，40 轮就能用，70 轮更稳。200 轮一般没必要 |
| 批大小 | 4 | 8G 显存用 4；爆显存降到 2 |
| 每 N 轮存档 | 10 | 每 10 轮导出一个中间模型到「模型」页，用于选模对比 |

勾选项（**默认全不勾，按需勾**）：

| 勾选 | 什么时候勾 |
|---|---|
| 从上次存档继续 | 上次训练中断过、想接着练。面板检测到没训完的记录时会**自动帮你勾上** |
| 重算特征 | 数据集换过素材、或上次特征提取失败时 |
| 训练完自动清理中间档 | 磁盘紧张才勾。**想跑选模对比就别勾**（对比要靠中间档） |
| 训练完生成选模对比 | 推荐勾：训完自动用同一句话把 final / e60 / e50 各唱一遍，进作品库 |
| 低音增强 | **别指望它治低音**。实测只是有限改善（把切片降 2/4 半音合成副本），特征提取时间 ×3 |

点「开始训练」后：

- 顶部进度条实时显示 `轮次 · 秒/轮 · 预计剩余时间`
- **mel 曲线往下走 = 在进步**；数字稳定在低位、不再下降 = 已经收敛
- 训练期间 **GPU 被占满，唱不了歌**（会自动排队/抢占），正常
- 想停就点「停止训练」——会真正停掉进程（不是假装停），最近一次存档保留

### 时长参考（8G 显存 / batch 4）

| 数据量 | 每轮 | 40 轮 | 70 轮 |
|---|---|---|---|
| 30 分钟 | ~2 分钟 | 1.5 小时 | 2.5 小时 |
| 60 分钟（低音增强 ×3） | ~5 分钟 | 3.5 小时 | 6 小时 |

## 3. 训练完之后

1. **模型**页会列出 `fishxxxx.pth`（最终）和 `fishxxxx_eN_sX.pth`（每 N 轮一个的中间档）。
2. **选模对比**：训练完（若勾了）会自动生成——同一句训练切片，final 和最后两个中间档各唱一遍，进作品库。听完选最喜欢的那档。
3. 在「模型」页**手动切换**到新模型（不会自动切）。
4. 中间档不听了的，在训练页底部「清理中间档」删掉（每个 ~53 MB）。

---

## 4. 变调（0.4.12 起）

「唱歌」页的变调是**整体变调**：人声和伴奏一起升降，不会跑出调外。

- 男声歌（原唱比她低很多）：推荐 **+4 ~ +6**，整首歌升到她的音区
- 女声歌：**0 ~ +2**，基本原调
- 想听低一点的：**-2 ~ -4** 也可以（但她音域下限大约 280Hz，再低就会"够不着"，听感发虚——这是模型能力边界，不是 bug）

## 5. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 点开始训练报「日志还在增长」 | 上一个训练刚停或还在跑。真停了就等 3 秒再点（面板会实测日志还长不长，不长就放行） |
| 训练中断：查不到任务 | 0.4.15 已修（网络抖动误报）。若再出现且训练日志也没在动，才需要真排查 |
| 训练完「模型」页没有新模型 | 看②里的进度信息是否真的到了 70 轮；`logs/<实验名>/` 里应有 `*.pth` |
| 低音还是不像 | 素材里低音太少（<2 分钟基本学不会）。**别靠低音增强硬堆**，只能缓解。根治要等真实低音素材 |
| 想从头重训 | 用新实验名（或删掉 `logs/<实验名>/`）。同实验名 + 勾「从上次存档继续」= 接着练 |
| 训练中断：已取消 | 你自己点的停止，不是故障 |
